# 《命に嫌われている》1080p60 字符动画：创作与工程说明 v0.1

## 一、确认的素材与交付规格
- 音频：用户提供的《命に嫌われている》FLAC；文件标签显示专辑《不器用な男》。
- 文件时长：267.973243 秒（约 4 分 28 秒），192 kHz / 24-bit / 双声道 FLAC。
- 目标视频：1920×1080、60fps，共 16,079 帧；MP4/H.264。
- 音频母带必须原样保存；最终可转 AAC 320kbps（44.1/48kHz）供广泛兼容，不应反复有损转码。
- 强度分析来自文件实际声音，不等于歌词逐句时间轴。以下段落时间是试听线索+曲式参考的**草案**，每句细分仍须人工校对。

## 二、主题与创意约束
这是对“正确话语与个人矛盾”的双重审视，不应简单投射成一个毫无责任的受害者对抗邪恶社会。叙述者也参与了冷漠与自相矛盾，而最后的重心从抽象批评落到希望具体的人继续活着。
- 黑色幽默应首先嘲讽制度性装饰和自我欺骗，不将真实死亡和具体人的痛苦当成笑点。
- 讽刺的视觉规则：宣传越漂亮，实际响应越空洞；批评别人的手，最终发现出自自己。
- 高潮不等于“反派被打败”，应表现残缺中的自我整合；结尾不过度治愈。
- 歌词中心：以语义转化为形象，少用直接打字字幕。出现的少量大字/提示，应为原创场景语言或合法的必要短引。

## 四、画面语言：可落地的规则
- 核心表现：字符作为“基本粒子”，同时可组成身体、屏幕、建筑、关系与场景。
- 角色应有一套不会随镜头变化而丢失的可识别外形，例如肩线、姿态和核心明暗节奏；避免仅靠随机粒子造人。
- “自我矛盾”用同一人的不同投影，冲突规则彼此抵消，而不是额外创造一个单纯邪恶的系统。
- 在第一次高潮用密度和压迫感，第二次高潮用群体递归，最终高潮则用更清晰、更少但更有力度的形态。
- 统一镜头语法：语义反转使用反向推进；每次复现“我们”就短暂显示摄影机与主角属于同一个系统。
- 绝大部分帧保证中低密度，让高密度冲击有对比；可读排版只在叙事必要时使用。

## 五、Codex 工程方案
- Vite + TypeScript + Three.js 或原生 WebGL2；统一 `renderFrame(tSeconds, seed)` 无状态确定性接口。
- 并行维护场景时间轴 JSON、角色生成规则、字体图集、后处理（字符映射、辉光、抖动、扫描）与音频同步。
- 先制作 15 秒竖向切片（建议第一次副歌 0:58–1:13）：必须有场景变形、角色、摄影机、节拍同步和讽刺语义，而非旋转几何体。
- 输出 360p/720p 的全曲预览做叙事审查，通过后才导出 1080p60 完整成片。
- FFmpeg 封装：严格取原音频时间轴、对视频 PTS 做同步；音画起点从 0 秒统一，末帧视频略多于音频不足一帧属于正常。
- 每个场景应独立测试 3 个固定时间点（开端/中段/结束），随机种子固定；再用抽帧拼图检查转场断裂和字体闪烁。

## 七、第一轮验收标准
1. 能重新生成相同时间点的同一帧（同场景同随机种子）。
2. 角色保持时空连续，不发生无意义镜头间跳变。
3. “嘲讽别人，却发现自己也参与其中”的转折能从画面读出来。
4. 结尾不是廉价治愈，而是小而真实的生命延续。
5. 输出的视频准确保持 1920×1080、60fps、原音轨同步。
